# Lesson 4: Phrases & Sentence Patterns

## 1. The ten phrases you'll use every day

| Japanese | Romaji | Meaning & use |
|----------|--------|---------------|
| すみません | **sumimasen** | *Excuse me / sorry / thank you (for the trouble)*. Use it to call staff, get past people, or apologise. Your most useful word. |
| ありがとうございます | **arigatō gozaimasu** | Thank you (polite). Quick version: **dōmo**. |
| お願いします | **onegaishimasu** | Please (I'd like that). Add it to any noun: *Bīru, onegaishimasu.* |
| ください | **~ kudasai** | Please give me ~: *Kore o kudasai.* |
| 大丈夫です | **daijōbu desu** | I'm OK / **No thank you** (polite refusal) |
| はい / いいえ | **hai / iie** | Yes / No. *Hai* also means "I'm listening". *Iie* sounds blunt, so people often say *chotto…* ("it's a bit…") instead. |
| わかりません | **wakarimasen** | I don't understand |
| わかりました | **wakarimashita** | Understood / OK |
| ごめんなさい | **gomen nasai** | I'm sorry (personal apology) |
| 英語、大丈夫ですか | **eigo, daijōbu desu ka?** | Is English OK? |

### Greetings
| | |
|---|---|
| **ohayō gozaimasu** | good morning |
| **konnichiwa** | hello, good afternoon |
| **konbanwa** | good evening |
| **oyasumi nasai** | good night |
| **hajimemashite, [name] desu** | nice to meet you, I'm [name] |
| **yoroshiku onegaishimasu** | pleased to meet you / I'm in your hands |
| **sayōnara** | goodbye (rather final; staff will say *arigatō gozaimashita*) |

### When you're lost in the conversation
| | |
|---|---|
| **mō ichido onegaishimasu** | once more, please |
| **yukkuri onegaishimasu** | slowly, please |
| **kaite kudasai** | please write it down |
| **nihongo ga sukoshi dake** | only a little Japanese |
| **[X] wa nihongo de nan desu ka?** | how do you say X in Japanese? |

### At the table
| | |
|---|---|
| **itadakimasu** | said before eating (≈ *bon appétit*) |
| **gochisōsama deshita** | said after eating, to staff as you leave |
| **oishii!** | delicious! |

## 2. Eight sentence templates

Japanese word order: **topic – object – verb**, with the verb **last**.
Small particles mark each word's role:
**wa** = topic ("as for…"), **o** = object, **ni** = to/at, **de** = by/with/at, **ka** = question (like a spoken "?").

Swap words into the slots:

### ① Where is ~?
**[X] wa doko desu ka?**
- *Toire wa doko desu ka?* · Where is the toilet?
- *Eki wa doko desu ka?* · Where is the station?

### ② ~, please (ordering, requesting)
**[X] o kudasai.** / **[X], onegaishimasu.**
- *Kore o kudasai.* · This one, please.
- *Mizu, onegaishimasu.* · Water, please.
- *Bīru o futatsu, onegaishimasu.* · Two beers, please.

### ③ Do you have ~?
**[X] wa arimasu ka?**
- *Eigo no menyū wa arimasu ka?* · Is there an English menu?
- *Wi-Fi wa arimasu ka?* · Is there Wi-Fi?
- Answer: *arimasu* (yes, there is) / *arimasen* (no, there isn't)

### ④ How much is ~?
**[X] wa ikura desu ka?**
- *Kore wa ikura desu ka?* · How much is this?

### ⑤ Is ~ OK? / Can I use ~?
**[X] de daijōbu desu ka?** / **[X] wa tsukaemasu ka?**
- *Kādo de daijōbu desu ka?* · Is a card OK?
- *Kādo wa tsukaemasu ka?* · Can I use a card?

### ⑥ May I ~?
**[verb-te] mo ii desu ka?**
- *Shashin o totte mo ii desu ka?* · May I take a photo?
- *Koko ni suwatte mo ii desu ka?* · May I sit here?
- *Shichaku shite mo ii desu ka?* · May I try it on?

### ⑦ I want to go to ~ / To ~, please
**[place] ni ikitai desu.** / **[place] made onegaishimasu.**
- *Asakusa ni ikitai desu.* · I want to go to Asakusa.
- *Kyōto eki made onegaishimasu.* · To Kyoto Station, please (taxi).

### ⑧ I am ~ / This is ~
**[X] desu.**
- *Futari desu.* · (We are) two people.
- *[Name] desu.* · I'm [name].
- *Igirisu-jin / Doitsu-jin / Furansu-jin / Pōrando-jin desu.* · I'm British / German / French / Polish.
  (country + **jin** = person from that country; *Yōroppa* = Europe)

Turn any statement into a question by adding **ka**: *Daijōbu desu.* (It's OK.) → *Daijōbu desu ka?* (Is it OK?)

## 3. Phrases you'll hear (and how to respond)

| You hear | Meaning | You reply |
|----------|---------|-----------|
| **irasshaimase!** | welcome! (shops, restaurants) | Nothing. A nod or smile is fine. |
| **nan-mei sama desu ka?** | how many people? | *Futari desu.* (+ fingers) |
| **shōshō omachi kudasai** | please wait a moment | *Hai.* |
| **dōzo** | go ahead / here you are | *Dōmo.* |
| **fukuro wa goriyō desu ka?** / **fukuro irimasu ka?** | do you need a bag? | *Onegaishimasu* / *Daijōbu desu* |
| **atatamemasu ka?** | shall I heat it up? | *Hai, onegaishimasu* / *Daijōbu desu* |
| **pointo kādo wa?** | do you have a points card? | *Nai desu.* (no) |
| **o-shiharai wa?** | how will you pay? | *Kādo de.* / *Genkin de.* |
| **tennai de omeshiagari desu ka?** | eating in? | *Tennai de.* (eat in) / *Mochikaeri de.* (take away) |
| **arigatō gozaimashita** | thank you (said as you leave) | *Dōmo* or *gochisōsama deshita* |
