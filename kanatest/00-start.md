# Kana Test: Hiragana and Katakana Together

You have learned both scripts in the [hiragana](../hiragana/00-start.md) and [katakana](../katakana/00-start.md) courses. These tests check how well you know them **side by side**: every test mixes the two, the way real signs, menus and station boards do.

There is no teaching here, only tests:

- **Reading**: see a character and pick or type its reading.
- **Listening**: hear a sound and pick the character, in the script asked for.
- **Twin pairs**: match each hiragana with the katakana for the same sound (あ ↔ ア).
- **Look-alikes**: tell apart characters that are easy to confuse, within a script and across the two.
- **Words**: read and hear real words in both scripts.

After every test, a report shows each character you met, coloured green (all right), amber (some wrong) or red (all wrong), and lists your weakest characters with a link to the course unit that teaches them. Nothing is saved, so take the tests as often as you like.
