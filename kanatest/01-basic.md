# 1. The Basic Characters

The 46 basic characters of each script: あ to ん and ア to ン. Every test mixes **hiragana and katakana**. There is no teaching here: each answer is marked at once, and at the end a report shows every character you met, coloured by how you did, with your weakest characters and a link to the unit that teaches them. Nothing is saved; take a test as often as you like.

## Reading

```kanatest
title: Reading · choose
desc: A character from either script: pick its reading.
kind: read
level: basic
count: 24
mode: choose
```

## Typing

```kanatest
title: Reading · type
desc: Type the reading in romaji (shi or si, tsu or tu are both fine).
kind: read
level: basic
count: 24
mode: type
```

## Listening

```kanatest
title: Listening
desc: Hear a sound and pick the character in the script asked for.
kind: listen
level: basic
count: 16
```

## Twin pairs

```kanatest
title: Twin pairs

kind: twins

count: 4

```
